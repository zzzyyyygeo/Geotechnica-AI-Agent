## 📊 实测结论（我跑出来的，不是推测）

### 你的原始知识库（Day5 建的）

| 关键词 | 命中块数 | 说明 |
|---|---|---|
| 地下工程 | **0** | 完全检不到 |
| 施工缝 | **0** | 完全检不到 |
| 一级防水 | **0** | 完全检不到 |
| 防水混凝土 | 20 | 勉强 |

原因：你的 PDF 是 **Adobe Image Conversion Plug-in** 生成的扫描件，
OCR 把「施工缝」输出成了「施 工 缝」，字被空格拆开 → 向量检索失明。

### 清洗 + 条文切分后

| 关键词 | 清洗前 | 清洗后 |
|---|---|---|
| 地下工程 | 0 | **129** |
| 施工缝 | 0 | **44** |
| 一级防水 | 0 | **1** |
| 防水混凝土 | 20 | **66** |

同时得到 **661 条结构化条文**，其中 **579 条（88%）带条文号**，可以精确引用。

### 修不了的（必须知道边界）

OCR 把「700」认成「3 O O」这类**字符级错认，正则永远修不了**。
实测清洗后「3 O O」仍出现 7 次。→ 只能换电子版文档。

## ⚠️ 专业层面的重要提醒

你用的《地下工程防水技术规范》**GB 50108-2008 已不是唯一依据**：

- **GB 55030-2022《建筑与市政工程防水通用规范》**（全文强制）已于 2023-04-01 实施
- 2008 版中大量强制性条文已被新规范替代

**求职时这是加分点**：能说出"我知道规范有版本效力问题，我的知识库需要更新到现行版本"，
比只会调 API 的候选人专业得多。

建议：去住建部官网或"国家标准全文公开系统"下载现行规范的**电子版（可复制文字）**，
你的 RAG 效果会立刻再上一个台阶。
